# SOL Pay 복구 및 기능 통합 안내

## 수정 기준
사용자 업로드 ZIP의 안쪽 `golla-card/` 최신 프로젝트를 기준으로 구성했습니다.
바깥쪽 `App.js`를 기준으로 하지 않았습니다.

## 복구·유지 기능
- 계좌·자산 연동 화면 없음
- 간편비밀번호(PIN) 설정 및 로그인
- 평소 일과 등록 및 메인에서 수정
- 특별 일정 기록 및 삭제
- 기존 5개 탭, 카드 목록, 결제, 챗봇, 설정 기능 유지
- 메인에 오늘 일정 기반 카드 혜택 후보 기능 추가
- GPS·위치권한 요청 없음

## 실행 (Windows CMD)
1. 이 ZIP을 Desktop 등에 압축 해제합니다. (원본 프로젝트 덮어쓰지 마세요.)
2. 압축을 푼 이 폴더를 VS Code에서 엽니다.
3. 터미널에서 `npm.cmd install`을 실행합니다.
4. `npx.cmd expo start --web -c` 실행 후 Chrome에서 웹 주소를 엽니다.

## 중요
- 계좌 또는 카드의 실제 소유 확인/금융기관 연동이 없는 시연용 앱입니다.
- 카드 혜택 후보는 상품 혜택 제목과 선택 일정의 키워드 매칭 결과입니다. 최적 카드 판단이 아닙니다.
- 개인정보, 실제 금융 비밀번호, 실제 상담 녹음은 사용하지 마세요.
- 미구현: 매일 아침 푸시 알림, 고객 유입 링크 추적, 실제 금융 API 및 실적 연동.

## 개발자 메뉴
메인 화면에서 `평소 일과 수정`과 `+ 특별 일정 기록`, 그리고 추가된 `오늘의 카드 혜택`을 확인하세요.
