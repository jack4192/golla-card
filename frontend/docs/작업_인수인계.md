## 3. 실행 방법
- 데모 모드: `npx expo start --go` → 웹 http://localhost:8081, 아이폰은 Expo Go로 QR
- 서버 모드(백엔드 연결): `.\scripts\start-with-backend.ps1` (이 PC의 LAN IP로 `EXPO_PUBLIC_API_URL` 설정)
- 백엔드: IntelliJ에서 폴더 열기 → 실행 목록 **Backend bootRun** ▶ (`.env` 자동으로 읽음) → http://localhost:8080
- 자세한 순서: `docs/새_노트북_설정.md`
- Vercel 재배포: `npx expo export --platform web` → `node scripts/prepare-vercel.js` → `dist` 내용을 **저장소 밖 폴더**로 복사 → 그 폴더에서 `npx vercel@latest link --yes --project solpay-demo` → `deploy --prod --yes`
  - 저장소 안에서 배포하면 git 작성자 정보 때문에 Vercel이 거절함

## 4. 백엔드 로컬 수정 3건 (팀 GitHub에는 아직 안 올림)
1. `application.yml`: `jwt:`가 `spring:` 안에 잘못 들여쓰기 돼 있던 것 수정 + `spring.config.import: optional:file:.env[.properties]` (`.env` 자동 읽기)
2. `config/SecurityConfig.java`: CORS 추가 (`CORS_ALLOWED_ORIGINS`, 기본 `http://localhost:8081,http://localhost:19006`)
3. `.run/Backend bootRun.run.xml`: IntelliJ 실행 설정
→ 팀원(백엔드 담당)에게 전달 필요

## 5. 백엔드 연동 현황
- **연동 완료(서버 모드):** 회원가입, 이메일·휴대폰 중복 확인, 로그인, 로그아웃, 내 정보(`/api/users/me`로 토큰 확인)
- 코드: `utils/api.js`, `App.js`(서버 모드 분기)
- **아직 서버 API 없음 → 기기 저장(데모)으로 동작:** 동의, 간편비밀번호(PIN), 카드, 일정, 추천, 결제
- 서버 모드 규칙
  - 서버 세션이 유효할 때만 PIN 로그인 화면을 보여줌(401/403/404면 이메일 로그인으로)
  - 다른 계정으로 로그인하면 이 기기의 이전 계정 데이터(동의·PIN·일정·카드) 삭제 후 처음부터
  - 동의·PIN이 기기에만 있어서, 새 기기에서 로그인하면 동의·PIN 설정부터 다시 함 (백엔드에 PIN·동의 API가 생기면 해결)
- API 명세: `docs/API_명세서.xlsx` (앱에서 쓰는 API 34개 중 6개 연동 완료, 앱 화면 없는 API 11개)

## 6. 지금까지 반영한 주요 화면 결정 (되돌리지 말 것)
- 카드 추천은 **신한카드만**. 맞는 카드 없으면 혜택 좋은 신한카드 1장 추천(하나카드 안내 삭제)
- 소비 분석 화면 2개 삭제, "주차별 혜택 시작" 그래프 삭제
- 결제 화면: QR 위에 "결제 카드 + 카드 변경" 줄, "승인 결과 보기"·"혜택 비교 조건"·"같은 거래로 내 카드 비교" 삭제, 예상 혜택 상자 정리(금액만 크게, 조건 미충족은 작은 주황 배지)
- 내 카드 순서: **☰ 손잡이 끌어서 변경**(수정 버튼 없음)
- 카드 탭 지갑 덱: 카드 넘기면 뒤 카드도 같이 애니메이션
- 일정: **일정 관리**(날짜별 목록, 아래 창에서 일정 변경·시간 재설정·삭제) / **일정 추가**(직접 입력 → 종류 → 시간 → 메모). 기타 칩 없음, 직접 입력이 맨 위
- 간편비밀번호: 설정 시 확인 틀리면 1단계부터, 변경은 작은 상자 안 3단계(현재→새→확인) 동그라미 입력
- 동의 화면: "[선택] 알림 수신 동의"(실제 알림 발송·권한 요청은 없음), 기기 알림 권한 박스 삭제
- 챗봇(SOL 카드 도우미): 홈·혜택·오늘의 일정·카드 탭에서 화면별 추천 질문, 결제 화면은 별도 결제 도우미
- 로그인·가입 이메일(아이디) 칸: 영어만, 한글 입력 시 "영어로 입력해주세요"
- 화면 미리보기(🔧) 버튼은 **웹·개발 중에만** 보이게 유지(최종 앱 배포본에서는 자동으로 안 보임)
- 카드 없는 결제 화면: 점선 카드 + 파란 카드 아이콘 + 분홍 하트(챗봇 캐릭터 사용 금지)
