# 새 노트북에서 이어서 작업하기

## 1. 설치할 프로그램
| 프로그램 | 용도 | 확인 명령 |
|---|---|---|
| Git | 코드 받기·올리기 | `git --version` |
| Node.js 24 (LTS) | 앱 실행 | `node -v` |
| Java 21 (JDK) | 백엔드 실행 | `java -version` |
| (선택) IntelliJ IDEA | 백엔드 편집 | |
| 아이폰: Expo Go 앱 | 휴대폰에서 앱 보기 | |

## 2. 앱(프론트) 받기
```powershell
git clone https://github.com/jack4192/golla-card.git SOLPay_FIXED
cd SOLPay_FIXED
git checkout front
npm install
```

## 3. 앱 실행
- 데모 모드(서버 없이): `npx expo start --go`
- 서버 모드(백엔드 연결): `.\scripts\start-with-backend.ps1`
  - 같은 노트북에서 백엔드가 켜져 있어야 해요(아래 4번).
- 웹으로 보기: 실행 후 브라우저에서 http://localhost:8081
- 아이폰: 같은 Wi-Fi에서 Expo Go로 터미널의 QR 코드 찍기
- 데모 계정: demo@example.com / Demo1234!  (데모 모드 기준)

## 4. 백엔드 실행 (IntelliJ, Spring Boot)
1. `backend_새노트북용.zip`을 옮겨서 압축을 풀어요. → `golla-card-feature-init-spring` 폴더
   (GitHub `feature/init-spring` + 수정: application.yml 들여쓰기·.env 자동 읽기, CORS, IntelliJ 실행 설정)
2. 이 노트북의 `golla-card-feature-init-spring\.env` 파일을 **메신저/USB로 따로** 옮겨서 같은 폴더에 넣어요.
   (팀 DB 비밀번호·JWT 비밀키가 들어 있어서 압축 파일에는 넣지 않았어요. 형식은 `.env.example` 참고)
3. IntelliJ → **Open** → `golla-card-feature-init-spring` 폴더 선택
   - Gradle 가져오기가 끝날 때까지 기다려요(오른쪽 아래 진행 표시).
   - File → Project Structure → SDK가 **Java 21**인지 확인해요.
4. 위쪽 실행 목록에서 **Backend bootRun** 을 고르고 ▶ 실행
   - `.env`를 자동으로 읽어서 따로 환경변수를 넣을 필요가 없어요.
   - `Started PaymateBackendApplication` 이 보이면 성공, 주소는 http://localhost:8080
5. 오른쪽 **Database** 패널의 `solpay@solpay-db…` 연결은 설정이 그대로 따라와요.
   처음 한 번만 연결을 더블클릭하고 **비밀번호(.env의 DB_PASSWORD)** 를 입력하면 돼요.

## 5. Vercel 다시 배포(멘토님 공유 링크)
```powershell
npx expo export --platform web
node scripts/prepare-vercel.js
```
그다음 `dist` 폴더 내용을 **git 저장소 밖의 폴더**로 복사해서 그 폴더에서:
```powershell
npx vercel@latest login
npx vercel@latest link --yes --project solpay-demo
npx vercel@latest deploy --prod --yes
```
(저장소 안에서 배포하면 git 작성자 정보 때문에 Vercel이 거절해요.)
- 공유 링크: https://solpay-demo-xi.vercel.app
