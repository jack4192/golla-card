# 새 노트북에서 이어서 작업하기

## 1. 설치할 프로그램

| 프로그램 | 용도 | 확인 명령 |
|---|---|---|
| Git | 코드 받기·올리기 | `git --version` |
| Node.js 24 (LTS) | 앱 실행 | `node -v` |
| Java 21 (JDK) | 백엔드 실행 | `java -version` |
| (선택) IntelliJ IDEA | 백엔드 편집 | |
| 아이폰: Expo Go 앱 | 휴대폰에서 앱 보기 | |

## 2. 코드 받기

```bash
git clone https://github.com/jack4192/golla-card.git
cd golla-card/frontend
npm ci
```

## 3. 앱 실행

- 서버 없이 보기: `npx expo start --go`
- 로컬 백엔드에 붙이기: `EXPO_PUBLIC_API_URL=http://<PC IP>:8080 npx expo start --go` (Windows는 `.\scripts\start-with-backend.ps1`)
- 배포 서버에 붙이기: `EXPO_PUBLIC_API_URL=https://paymate.duckdns.org npx expo start --go`
- 웹으로 보기: 실행 후 http://localhost:8081
- 아이폰: 같은 와이파이에서 Expo Go로 터미널의 QR 코드 찍기
- 예시 계정(서버 없이 볼 때): `demo@example.com` / `Demo1234!`

## 4. 백엔드 실행 (IntelliJ)

1. IntelliJ → **Open** → 저장소의 `backend/` 폴더를 엽니다.
2. `backend/.env.example` 을 `backend/.env` 로 복사하고, DB 비밀번호·JWT 키는 팀원에게 따로 받아 채웁니다 (깃에는 올리지 않습니다).
3. File → Project Structure → SDK가 **Java 21** 인지 확인합니다.
4. Gradle 작업 `bootRun` 을 실행합니다. `Started PaymateBackendApplication` 이 보이면 http://localhost:8080 에서 받습니다.

## 5. 웹 배포

`main` 브랜치에 올리면 AWS Amplify가 자동으로 다시 배포합니다 (2분 정도). 따로 빌드해서 올릴 필요는 없습니다.
