# SOL페이 발표·시연용 웹 버전

이 프로젝트는 원본 Expo 앱의 화면 흐름을 유지하면서 AWS Amplify에서 시연할 수 있도록 변경한 프론트엔드 코드입니다.

## 빠른 시작 (Windows)
1. 압축을 풀어 `App.js`와 `웹배포_실행.cmd`가 같은 폴더에 있는지 확인하세요.
2. `웹배포_실행.cmd`를 실행합니다. Node.js / npm과 인터넷이 필요합니다.
3. 성공하면 `solpay-web-ready.zip`을 기존 AWS Amplify `main` 브랜치에 재배포합니다.
4. 테스트 로그인: **demo@example.com / 1234**. 실제 계정·결제 서버는 없습니다.

## 주의 사항
- 회원가입은 체험용입니다. 가입 이메일과 비밀번호 해시는 같은 탭의 실행 중 메모리에서만 사용되며, 새로고침하면 초기화됩니다. 실제 개인정보나 실사용 비밀번호는 입력하지 마세요.
- 브라우저 PIN·동의·진행 상태는 **sessionStorage** 기반의 데모 데이터입니다. PIN은 SHA-256 + salt로 보관되지만 금융 서비스용 인증 보안은 전혀 아닙니다.
- 데모 카드, 마이데이터, 혜택, QR, 바코드 및 결제는 실제 금융 기능이 아닙니다.
- Expo Go에서는 기존 모바일용 SecureStore, Haptics, Brightness와 폭죽 효과를 사용합니다. 웹에는 해당 기능의 안전한 대체 처리가 있습니다.
- `data/paymentBenefits.js`는 추후 AI 연동용 참고 규칙이며, 결제 화면에 수동 금액·실적 입력을 다시 추가하지 않았습니다.

더 자세한 설명은 `README_시작방법.txt`를 보세요.
