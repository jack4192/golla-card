# 가상 소비 데이터 v2 (1005명) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 같은 생성 코드에 v2 설정을 겹쳐 1005명·1년 데이터(parquet + 팀 DB 폴더)를 만들고, v1 결과는 그대로 둔다.

**Architecture:** `SOLPAY_DATA_VERSION=v2` 이면 `load_config` 가 `config/v2/*.yml` 을 기본 설정 위에 깊게 합치고 결과를 `out_v2` 에 쓴다. 새 동작(칸별 인원, 카드 수 분포, 나이대 효과, 교대 근무, 외근 동네, 학원비 비율)은 v2 설정에 키가 있을 때만 켜지고, v1 경로의 난수 소비는 바꾸지 않는다.

**Tech Stack:** Python 3 (uv), numpy, pandas, pyarrow, PyYAML, pytest. 작업 폴더 `~/Desktop/solpay/data`.

**Spec:** `docs/superpowers/specs/2026-11-22-data-v2-1000-design.md`

## Global Constraints

- v1 결과(`data/out/parquet`, `카드서비스_DB_1년`, `카드서비스_DB_1년.zip`)는 바이트까지 그대로. v1 export 는 돌리지 않는다.
- 팀 DB 23표의 이름·칼럼·제약은 v1 과 같다. 새 값은 `persona_code` 5개(HOMEMAKER·SELFEMP·SHIFT·FIELD·RETIRED)와 `age_band` 의 `60s` 뿐.
- 기간 2025-11-01 ~ 2026-11-05T10:00+09:00, 시드 20261127 (v1 과 같음).
- 배경 1000명(user_id 1001~2000) + 데모 5명. 팀 DB 번호는 test1~5 = 1~5, 배경 = 6~1005.
- 나이대 효과·차량 나이 배율·학원비 비율은 배경 사용자에게만. 데모 5명의 소비 패턴과 amount_level 은 v1 그대로.
- 커밋은 하지 않는다 (사용자 요청 시).
