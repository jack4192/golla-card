# v2.1 개인 루틴 데이터 + 업종 모델 튜닝·개인 습관 반영 실험 (2026-11-23)

## 왜
사용자 요구: 전체 사용자 데이터로 학습하되 그 사람의 소비 패턴이 가장 잘 반영되게. 예) 8~9시 커피가 월 10회 이상이면 그 시간대 커피에 강한 가중치.
v2 확인 결과: 생성기가 업종을 직업·나이대 확률로 결제마다 새로 뽑아 개인 루틴이 없다. "최근 30일 같은 시각 ±1시간 같은 업종 10회+"는 배치의 0.8%,
그때도 실제 그 업종은 50%, 모델 확률 51%. 습관 입력을 더해도 적중 38.13% 그대로. → 루틴이 있는 데이터가 있어야 설계를 평가할 수 있다.
v2 에서 업종 예측이 완벽하면 혜택률 1.318 → 1.538% (7월~11-05): 업종 모델로 얻을 수 있는 최대 몫 +0.22%p.

## 사용자 결정
- 데이터: v2 는 그대로, 루틴을 넣은 새 판 v2.1. 루틴 '보통' = 배경 50%가 직업에 맞는 루틴 1~2개, 정해진 시각 ±30분, 해당 요일 60~90%.
  결제 수를 늘리지 않고 월 지출은 비슷하게. 데모 5명은 그대로.
- 튜닝: 업종 모델(LightGBM) 설정값만, 약 30조합. 학습 가중치·확률 보정·엔진 기준값은 하지 않는다.
- 입력 비교: 나이(생년월일) + 직장명 직업 7가지 — 앱이 실제로 아는 값만.
- 개인 습관 반영: ① ML 입력 ② 규칙(같은 시각 n회 이상 → 그 업종 확률 하한) ③ 둘 다를 재생으로 비교. n·하한은 튜닝.
- 고르는 기준: 재생 혜택률, 단 습관보다 덜 받는 사용자 수가 지금(current)보다 늘면 제외. 탐색 규모 보통.

## 데이터 (data/generate, config/v2.1)
- 설정 겹치기: 점이 있는 판은 큰 판 위에 겹친다 (`version_chain("v2.1") = [v2, v2.1]`).
- 루틴 정하기는 따로 뽑은 난수(seed, user_id, 2101) → 루틴이 없는 사용자의 결제는 v2 와 똑같다 (테스트로 확인).
- 직업별 루틴 후보와 가중치: `config/v2.1/distributions.yml` (내 판단: 출근길 커피·편의점·빵집, 점심 식당·패스트푸드·점심 후 커피,
  오전 카페·장보기·빵집, 오후 카페, 퇴근길 편의점·장보기, 늦은 밤 편의점, 주말 브런치, 교대근무는 그 주 출근 10~40분 전).
- 결제 수·지출 맞추기 (내 판단, 세 번 시도): 그날 같은 종류 결제를 루틴으로 옮김 → 없으면 금액 3배 안의 비슷한 결제를 바꿈 →
  없으면 새로 만들고 뒤의 날 같은 종류·비슷한 금액 결제를 뺌. 무조건 추가는 결제 +8.5%, 무조건 바꾸기는 루틴 사용자 지출 −9.6%였다.
- 결과: 결제 1,066,005건(v2 대비 +2.1%), 배경 월 지출 중앙 +0.4%, 루틴 사용자 525명·758개, 평일 루틴 월 15회(10회+ 90%).

## 실험 (solpay-ai/artifacts/data_v2_1/tune, 엔진 코드 변경 없음)
- 설정값 탐색: 1~4월 학습, 5~6월 검증 로그 손실. 지금 값 + 무작위 29개.
- 후보: current(지금 값) / tuned / tuned+습관 입력 / tuned+나이·직업 / tuned+둘 다. 1~6월 학습(85/15 조기 종료).
- 규칙: tuned 위에 n∈{6,8,10} × 하한∈{0.6,0.8}, 7~8월 재생으로 고르고 tuned·tuned+습관 위에 7월~11-05.
- 재생 조건은 v2 그룹 실험과 같음 (일정 30·10% + 팝업 + 팀 DB 프로모션 + 1순위). 신규 가입자는 칸마다 20%를 7월 가입으로.

## 자주 가는 가게(브랜드) 예측 실험 (2026-11-23, artifacts/data_v2_1/tune/brand_exp.py·run_brand.py, 엔진 코드 변경 없음)
사용자 결정: 같은 시각에 자주 가는 가게를 맞혀 프로모션 카드를 고르면 상한과의 차이를 얼마나 메우는지 재생으로 잰다.
기준(L=0)은 서비스 기본 모델 파일(artifacts/data_v2_1/category_lgbm.txt) 그대로라 실험용 current(1.316%)와 0.008%p 다르다 — 같은 설정을 따로 학습한 차이로, 이 정도는 잡음이다.

- 가게 가중 조합 10개(기록 30·90일 × 가중 1·3·10배·확정, 프로모션만 3배)는 7~8월에 모두 1.260~1.262%로 기준 1.261%와 같다. 35명 시험의 +0.016%p 는 표본 잡음이었다.
- 상한과의 차이 1,311만 원 중 **업종을 맞히는 몫이 1,133만 원(86%)**, 가게까지 맞히는 몫 167만 원(13%), 금액 11만 원(1%).
  앞 절의 "프로모션 몫 51% = 가게를 알아야 얻는 몫"은 고친다: 업종만 알아도 내 그 업종 브랜드 이력으로 프로모션 카드가 대부분 맞게 골라진다.
- 결론: 막힌 곳은 가게가 아니라 업종이다. 남은 업종 오답은 루틴이 아니라 직업·나이대 확률로 무작위로 뽑힌 결제라(루틴 없는 사용자도 차이가 같다), 이 데이터에서는 더 맞히기 어렵다.
