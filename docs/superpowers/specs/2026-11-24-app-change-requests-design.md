## 1. 카드 탭 · 미보유 카드 상세

- '보유 카드로 등록' 버튼을 없앤다. 지갑에 카드를 직접 넣는 다른 길은 만들지 않는다 (사용자 결정 '그대로 없애기').
- 상세 아래 버튼:
  - 미보유 카드: 흰 '닫기' + 파란 '카드 신청'.
  - '카드 신청'은 카드사 신청 페이지(`sourcePage`, 40장 중 34장)를 연다. 주소가 없는 카드는 '닫기'만 둔다 (내 판단).
  - 보유 카드: '지갑에 등록된 카드' 표시와 '닫기'만 둔다. 지금처럼 파란 '닫기' 하나 (내 판단).

## 2·4. 카드 자동 배치 (켜기/끄기 하나로 묶음)

**상태 하나: 자동 배치 ON/OFF** (사용자 결정 '하나로 묶기')
- 기본은 ON 이다. 이 기기에 저장한다(앱 저장소). 서버에는 저장하지 않는다 (내 판단).
- 이 상태를 보여 주는 곳은 두 군데다.
  - 홈 '내 지갑' 제목 오른쪽 스위치.
  - 홈 '내 카드' 오른쪽 위 '자동 배치 적용' 버튼. ON 이면 파랗게 켜지고, OFF 면 회색이다.

**ON 일 때**
- 홈 '내 카드' 순서는 지금 시각 AI 추천 순서다. AI 배치 미리보기를 쓰고 기록은 남기지 않는다.
- 맨 위 카드가 결제 카드다 (지금 동작).
- 시간대가 바뀌거나 홈에 돌아오면 다시 묻는다.

**OFF 일 때 (사용자 결정 '카드 순서만 수동')**
- 홈 '내 카드'는 내가 정한 순서이고, 맨 위가 결제 카드다.
- 결제 화면은 목록을 AI 순서로 세우지 않고, AI 1순위를 결제 카드로 자동 선택하지 않는다.
- 결제 화면의 'AI 추천' 상자는 그대로 보인다. "AI가 맨 앞에 둔 카드는 …예요 · 이 카드로 바꾸기" 같은 조언이다.
- 홈 일정 카드의 AI 추천, 시간 표시줄 미리보기, 혜택 추천 팝업은 그대로다.

**켜고 끄기**
- 스위치를 끌 때 확인 창을 띄운다.
  - 제목: 자동 배치를 끌까요?
  - 본문: 끄시면 할인과 프로모션 혜택을 못 받으실 수 있어요!
  - [취소]는 그대로 두고, [확인]은 OFF 한다.
- 스위치를 켜거나 '자동 배치 적용'을 누르면 바로 ON 이 되어 AI 추천 순서로 돌아간다. 확인 창은 없다.
- 스위치로 끄면 지금 보이는 순서를 내 순서로 저장한다. 끄는 순간 목록이 갑자기 바뀌지 않게 하려는 것이다 (내 판단).

**직접 순서 바꾸기** (사용자 결정 '자동 배치 중일 때만')
- ON 일 때 순서를 바꾸면 확인 창을 띄운다. 카드를 눌러 맨 위로 올리기와 ☰ 끌기 모두 해당한다.
  - 제목: 정말로 카드 순서를 바꾸시겠습니까?
  - 본문: 바꾸면 AI 자동 배치가 꺼지고 정한 순서대로 써요. '자동 배치 적용'으로 언제든 되돌릴 수 있어요.
  - [취소]는 원래 순서로 돌려놓고, [바꾸기]는 순서를 저장하고 OFF 한다.
- OFF 일 때는 확인 없이 바로 바꾼다.

**안내 문구**
- 홈 맨 아래(프로모션·혜택 아래)에 작은 글씨로 둔다 (내 판단):
  > 본 시스템은 AI를 활용한 카드 자동 배치 및 추천으로 부정확한 안내가 포함될 수 있습니다. 평소 소비가 아주 적은 편이거나 불규칙적이신 분께는 일부 오안내가 섞일 수 있습니다.

**데모 모드** (서버 없음)
- AI 순서가 없어서 ON 이어도 내 순서를 보인다. 스위치와 버튼은 그대로 보인다.

## 방법

| 안 | 내용 | 결과 |
|---|---|---|
| 기기 저장 (고른 안) | 자동 배치 상태를 앱 저장소에 두고, 홈과 결제 화면이 같은 상태를 읽는다 | 백엔드·DB 변경이 없다 |
| 서버 저장 | 사용자 설정 칸을 users 표에 추가한다 | 기기를 바꿔도 유지되지만 DB 칸 추가·RDS 반영·백엔드 API 가 필요하다. 시연 범위에 비해 크다 |
