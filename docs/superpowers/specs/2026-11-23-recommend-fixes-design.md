# 일정 맞춤 추천 바로잡기 (짧은 설계서)

날짜: 2026-11-23

## 왜

사용자가 1번 계정에서 '일정 맞춤 추천' 화면을 보고 두 가지를 지적했다.

- **카드 추천 탭이 나라사랑카드 → 신한 모두의카드로 바뀐다.** 앱이 먼저 자기 계산(옛 22장 데이터, 혜택 이름만 보고 맞춤)을 보이다가, AI 답이 약 3초 뒤에 오면 갈아 끼운다.
- **프로모션이 하루 일정과 상관없다.** 1번 계정의 오늘 일정은 직접 입력 '영화관'(18:00~19:00, 17:39 저장)이다. 저장할 때의 옛 백엔드는 직접 입력을 AI 에 넘기지 않아 AI 는 '오늘 일정 없음'으로 보았다. 그래서 평소 소비(카페)로 할리스·메가MGC커피를 골랐다. 지금 백엔드는 직접 입력을 분류해 넘기지만('영화관' → MOVIE), 일정을 저장할 때만 넘긴다.

조사하며 하나를 더 찾았다.

- **카드 DB 누락.** 지금 카드 DB(팀 '최종 카드 DB'를 그대로 옮긴 `data/config/card_db`, 40장)에 옛 22장 데이터의 혜택 일부가 없다. 비교 결과는 메모리 project-final-card-db 에 있다.

## 사용자 결정 (2026-11-23)

1. **일정 다시 맞추기.** 맞춤 추천을 부르기 전에 백엔드가 AI 의 오늘 일정과 서버 일정을 비교하고, 다르면 다시 넘긴다.
   - 같은 안: 이번만 다시 넘기기(거절), 평소 소비 행사 숨기기(거절).
2. **카드 추천 탭은 '불러오는 중'.** 서버 모드에서는 AI 답이 올 때까지 불러오는 중을 보인다.
   - AI 가 실패하거나 카드를 주지 못할 때(결제 내역 없는 새 가입자)만 앱 계산 카드를 보인다.
   - 데모 모드는 지금처럼 앱 계산.
   - 같은 안: 앱 계산 없이 AI 만(거절).
3. **나라사랑카드는 계속 제외(자격 제한 유지).**
   - 제한을 풀면 365명 중 233명(64%)이 일정 없이도 이 카드를 1순위로 받는다. 연회비 0원에 편의점·대중교통 20% 캐시백이라서다.
   - 가상 사용자에게는 군 장병 여부가 없다.
   - 앞서 고른 '허용 + 자격 안내'를 이 수치를 보고 바꿨다.
4. **누락 혜택 6줄을 아래 가정으로 넣는다.** 업종이 새 DB 에 있는 것만이다.

## 설계

**A. 카드 데이터 (같은 6줄을 모든 사본에)**
- 원본: `data/config/card_db` 의 benefits·benefit_tiers·benefit_targets·card_perks.
  - 새 번호: 혜택 284~289, 구간 674~694, 대상 662~674.
  - 브랜치는 ai 이고, 커밋할 때 final 에 합친다.
- 팀 DB 내보내기 `카드서비스_DB_1년`, `_v2`, `_v2.1`: 위 4개 표를 원본에서 복사한다. export_db 의 COPY 와 같은 규칙이고, 깃에는 없다.
- 로컬 DB `solpay_backend`·`solpay_v21`: SQL 하나로 넣는다.
  - SQL 파일: `backend/shared-db/restore_card_benefits_20261123.sql`.
  - 여러 번 실행해도 같은 결과가 나오게 쓴다. 이미 있으면 건너뛰고, 자동 번호도 맞춘다.
- 공용 RDS: 같은 SQL 을 사용자가 마스터 계정으로 실행한다. 나는 RDS 에 쓰지 않는다.
- 앱 `frontend/data/cardCatalog40.json`: 5장에 혜택 항목을 더한다. note 형식은 기존 항목과 같게 맞춘다.

**B. 백엔드: 추천 전 일정 맞추기**
- `ScheduleAiSync.ensureSynced(userId, day)`
  - 서버 일정으로 만든 항목(itemsFor)과 AI 의 그날 일정(GET)을 비교한다. 비교 칸은 start·end·category·amount·brand 이다.
  - 다를 때만 PUT 한다. PUT 하면 AI 가 그날 추천 캐시를 버리고 새로 계산한다.
  - 실패하면 경고만 남기고 넘어간다. 추천은 그대로 부른다.
- `AiController.recommendationPage` 가 AI 를 부르기 전에 `ensureSynced(id, ai.today())` 를 부른다.

**C. 앱: 카드 추천 탭**
- 순수 함수 `cardSource({ serverMode, today, aiState, aiCard })` 는 `'loading' | 'ai' | 'local'` 을 돌려준다(`utils/aiRecommendCore.js`).
- `RoutineRecommendationScreen` 은 aiState(loading/ready/failed)를 두고, loading 이면 카드 자리에 불러오는 중 표시를 보인다.
- 프로모션 탭과 탭 규칙은 지금 그대로다.
