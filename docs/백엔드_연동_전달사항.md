# 백엔드 연동 전달사항 (백엔드 담당자께)

작성: 2026-11-23 · 기준: GitHub `feature/init-spring` + 로컬 수정 3건
(이전 노트북에 있던 같은 이름의 문서를 새 노트북에서 다시 정리한 것입니다.)

앱(프론트)을 백엔드에 붙이면서 아래 3가지를 로컬에서 고쳤습니다. 팀 저장소에는 아직 반영되지 않았으니 확인 후 반영 부탁드립니다.

---

## 1. `src/main/resources/application.yml`

**문제:** `jwt:` 블록이 `spring:` 안으로 들여쓰기 돼 있어서 `jwt.secret`을 못 읽었습니다.
**수정:** `jwt:`를 맨 바깥(최상위)으로 옮기고, 프로젝트 폴더의 `.env`를 자동으로 읽도록 한 줄 추가했습니다.

```yaml
spring:
    application:
      name: paymate-backend

    # 프로젝트 폴더의 .env(DB 접속 정보·JWT 비밀키)를 자동으로 읽습니다. 없으면 환경변수를 씁니다.
    config:
      import: optional:file:.env[.properties]

    datasource:
      url: jdbc:postgresql://${DB_HOST}:5432/${DB_NAME}
      username: ${DB_USERNAME}
      password: ${DB_PASSWORD}
      driver-class-name: org.postgresql.Driver

    jpa:
      hibernate:
        ddl-auto: validate

jwt:
  secret: ${JWT_SECRET}
  access-token-expire-time: 3600000
```

- `optional:`이라서 `.env`가 없어도 서버는 뜨고, 그때는 OS 환경변수를 씁니다.
- `.env`에 들어갈 항목은 `.env.example`과 같습니다: `DB_HOST`, `DB_NAME`, `DB_USERNAME`, `DB_PASSWORD`, `JWT_SECRET`
- `.env`는 `.gitignore`에 들어가 있어야 합니다(비밀번호가 들어 있음).

## 2. `src/main/java/com/paymate/backend/config/SecurityConfig.java` — CORS 추가

**이유:** 웹(Expo 웹 `localhost:8081`, Vercel)에서 API를 부르면 브라우저가 CORS로 막습니다. (아이폰 앱은 영향 없음)

**추가한 것:**
- `corsConfigurationSource` Bean — 허용 주소는 설정값 `cors.allowed-origins`(환경변수 `CORS_ALLOWED_ORIGINS`, 쉼표 구분)
  - 기본값: `http://localhost:8081,http://localhost:19006`
  - 대상 경로: `/api/**`
  - 허용 메서드: GET, POST, PUT, PATCH, DELETE, OPTIONS
  - 허용 헤더: `Authorization`, `Content-Type`
- `securityFilterChain`에 `.cors(Customizer.withDefaults())` 추가

```java
@Bean
public CorsConfigurationSource corsConfigurationSource(
        @Value("${cors.allowed-origins:http://localhost:8081,http://localhost:19006}") String allowedOrigins) {
    CorsConfiguration config = new CorsConfiguration();
    config.setAllowedOriginPatterns(Arrays.stream(allowedOrigins.split(","))
            .map(String::trim).filter(origin -> !origin.isEmpty()).toList());
    config.setAllowedMethods(List.of("GET", "POST", "PUT", "PATCH", "DELETE", "OPTIONS"));
    config.setAllowedHeaders(List.of("Authorization", "Content-Type"));
    config.setMaxAge(3600L);
    UrlBasedCorsConfigurationSource source = new UrlBasedCorsConfigurationSource();
    source.registerCorsConfiguration("/api/**", config);
    return source;
}
```

- Vercel 주소로 서버를 붙일 때는 `CORS_ALLOWED_ORIGINS=https://solpay-demo-xi.vercel.app,http://localhost:8081`처럼 넣으면 됩니다.

## 3. `.run/Backend bootRun.run.xml` — IntelliJ 실행 설정 (새 파일)

- IntelliJ 실행 목록에 **Backend bootRun**이 생깁니다(Gradle `bootRun` 실행).
- 팀원 모두 같은 실행 버튼을 쓰게 하려면 저장소에 함께 올려도 됩니다. 원치 않으면 빼도 서버 동작에는 영향 없습니다.

## 참고: 앱 연동 현황

- **연동 완료:** 회원가입, 이메일·휴대폰 중복 확인, 로그인, 로그아웃, 내 정보(`/api/users/me`)
- **앱에서 필요하지만 서버 API가 아직 없는 것:** 동의, 간편비밀번호(PIN), 카드, 일정, 추천, 결제
  - 지금은 기기에만 저장돼서, 새 기기에서 로그인하면 동의·PIN 설정을 다시 해야 합니다.
  - 특히 **PIN·동의 API**가 생기면 이 문제가 바로 해결됩니다.
- 전체 목록: 앱 저장소 `docs/API_명세서.xlsx` (앱에서 쓰는 API 34개 중 6개 연동 완료)
