# 새 노트북에서 이어서 작업하기

## 1. 설치할 프로그램
| 프로그램 | 용도 | 확인 명령 |
|---|---|---|
| Git | 코드 받기·올리기 | `git --version` |
| Node.js 24 (LTS) | 앱 실행 | `node -v` |
| Java 21 (JDK) | 백엔드 실행 | `java -version` |
| (선택) IntelliJ IDEA | 백엔드 편집 | |
| 아이폰: Expo Go 앱 | 휴대폰에서 앱 보기 | |

## 2. 앱(프론트) 받기
```powershell
git clone https://github.com/jack4192/golla-card.git SOLPay_FIXED
cd SOLPay_FIXED
git checkout front
npm install
```

## 3. 앱 실행
- 데모 모드(서버 없이): `npx expo start --go`
- 서버 모드(백엔드 연결): `.\scripts\start-with-backend.ps1`
  - 같은 노트북에서 백엔드가 켜져 있어야 해요(아래 4번).
- 웹으로 보기: 실행 후 브라우저에서 http://localhost:8081
- 아이폰: 같은 Wi-Fi에서 Expo Go로 터미널의 QR 코드 찍기
- 데모 계정: demo@example.com / Demo1234!  (데모 모드 기준)

## 4. 백엔드 실행 (Spring Boot)
1. 백엔드 폴더 `golla-card-feature-init-spring`을 USB/드라이브로 옮겨요.
   (GitHub `feature/init-spring` 브랜치 + 수정 2건: application.yml 들여쓰기, CORS)
2. 폴더 안에 `.env` 파일을 만들고 팀에게 받은 값을 넣어요. **이 파일은 메신저로만 따로 전달하세요.**
   ```
   DB_HOST=
   DB_NAME=
   DB_USERNAME=
   DB_PASSWORD=
   JWT_SECRET=
   ```
3. PowerShell에서 `.env` 값을 넣고 실행:
   ```powershell
   Get-Content .env | ForEach-Object { $k,$v = $_.Split('=',2); if ($k) { Set-Item "Env:$($k.Trim())" $v.Trim() } }
   $env:CORS_ALLOWED_ORIGINS = 'http://localhost:8081,http://localhost:19006'
   .\gradlew.bat bootRun
   ```
4. http://localhost:8080 에서 동작해요.

## 5. Vercel 다시 배포(멘토님 공유 링크)
```powershell
npx expo export --platform web
node scripts/prepare-vercel.js
```
그다음 `dist` 폴더 내용을 **git 저장소 밖의 폴더**로 복사해서 그 폴더에서:
```powershell
npx vercel@latest login
npx vercel@latest link --yes --project solpay-demo
npx vercel@latest deploy --prod --yes
```
(저장소 안에서 배포하면 git 작성자 정보 때문에 Vercel이 거절해요.)
- 공유 링크: https://solpay-demo-xi.vercel.app
